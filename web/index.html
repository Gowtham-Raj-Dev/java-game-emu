Made for old games

Set up for you, every time

Auto screen size

Reads the game's own images and manifest to pick 128×128, 176×208, 240×320 or 320×240. You can change it from the ☰ menu.

Portrait, landscape, turned

Landscape games open sideways with the D-pad left and number keys right. Games that draw sideways are turned upright, and you can turn any game from the menu.

Touch games

Games made for touch phones hide the keypad and fill the screen. A small ☰ button stays in the corner for the menu.

Record videos

Choose Record video in the ☰ menu to capture a sharp gameplay video with the game's music. Choose Stop recording to save it.

Saves kept

High scores and progress stay on your device between sessions.

Own engine

A Java bytecode VM, MIDP 2.0 and the Nokia UI API written from scratch. That is why the app is only 175 KB.

Controls

A keypad that feels like the phone

Every key sends the same code an old Nokia would, so games react the way they were made to.

D-pad + OK
Move and select. Slide your thumb to change direction without lifting it.
Soft keys ▬ ▬
Left and right keys under the screen: menus, pause, back. Their labels show on the keys.
0–9 * #
Number keys. Many games also move with 2 4 6 8 and fire with 5.
☰ or Back
Pauses the game and opens the menu: keypad on/off, rotate screen, screen size, sound, record video, restart, exit.
Touch
Tap the game screen in touch games. Taps line up with the picture even when it is turned.
Keyboard (browser)
Arrows, Enter = OK, F1 / F2 = soft keys, 0–9, * and #, Esc = menu.

FAQ

Questions people ask

Android says the app is from an unknown source. Is it safe?

JavaPlay is not on the Play Store, so Android shows this warning for any app installed from a website. The app asks for no permissions except vibration, needs no account and shows no ads.

I only have a .jad file. What do I do?

A .jad file is only a description. The game itself is in the .jar file. Download the .jar version instead.

The game looks too small or cut off.

Open the ☰ menu while playing and choose Screen size. Pick the size the game was made for, often 240×320. The game restarts with the new size.

The game shows sideways.

Open the ☰ menu and tap Rotate screen until it is upright (Off, Left, Right). JavaPlay remembers the choice for that game.

Does every Java game work?

JavaPlay supports 2D games made for MIDP 1.0/2.0 and Nokia phones. 3D games (M3G, Mascot Capsule) and online features are not supported yet. If a game fails, try another screen size from the ☰ menu.

Can I play on a computer?

Yes. Open Play in browser, add a .jar and use the keyboard or click the keypad. Use a recent Chrome or Edge.
